# Codeforces Solutions

This repository contains my solutions to **Codeforces** problems, written during contests and practice sessions.
The primary purpose of this repository is **learning, revision, and personal reference**.

It also bundles my **CP-SoS** (Competitive Programming — Summer of Skills) notes and resources.

Most solutions are implemented in **C++**, following a personal competitive programming template.

## 📌 Details

### 🔹 Old Rounds
- Solutions from **live Codeforces rounds** (Div2, Div3, Educational, Global, seasonal specials).
- Each round is its own directory; problems are named `Q1.cpp`, `Q2.cpp`, … or by descriptive names when revisited.

### 🔹 Practice
- **Rounds/** — full rounds solved virtually or post-contest, organized by round number and division.
- **Old/** — individual problems, topic-wise drills, and older practice files named by problem title or Codeforces ID.

### 🔹 CP-SoS
- Notes, materials, and problem sets from the **Summer of Skills — Competitive Programming** track.
- Split into *Before Midterm* and *After Midterm* phases, with additional reference and planning material.

### 🔹 cfcontest.sh
- Bash helper that creates a new contest folder under `Practice/` with `A.cpp`–`D.cpp` copied from `template.cpp` and a `run` script for quick `g++ -std=c++17 -O2` compile+run.
- Usage: `./cfcontest.sh "1108 Div. 2"`

### 🔹 template.cpp
- My personal **competitive programming template** used as the base for most submissions.
